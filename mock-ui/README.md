# Soft Future Companion Intake - Mock UI

Clickable kiosk mock driven by the Stitch project **Soft Future Companion Intake** (`695494198560560923`).

**Flow:** Welcome → Self → Desire → Matches → Generating → Reveal

## Run

```bash
npm run mock
```

From this folder: `npm install && npm run dev`

## Stitch assets

Downloaded HTML + screenshots live in `stitch/`. Runtime images are in `public/stitch/`.

Re-fetch (requires `STITCH_API_KEY`):

```bash
# see scripts in chat history / use @google/stitch-sdk getHtml + getImage
```
